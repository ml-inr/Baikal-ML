# Prefilter: DA vs no-DA control, with h8s3

Two runs differing only in `max_lambda` (0.05 vs 0.0).

| file | what |
|---|---|
| `run_scoring.sh` | scoring commands for both models |
| `prefilter_da_vs_control.ipynb` | the analysis — imports `inference.reader`, carries its own tools, draws both models on every figure |
| `scored_parts/` | the part lists `run_scoring.sh` chose |
| `figures/` | output, regenerated by the notebook |

## Cuts

| figure | cut | source of the counts |
|---|---|---|
| 1, 2, 3 | h8s3 on **MC truth** | `n_gt_sig_hits >= 8 AND n_gt_sig_strings >= 3` (`raw/labels != 0`) |
| 4 | h8s3 by the **sig-noise model**, both exp_full and muatm | `n_sn_hits >= 8 AND n_sn_strings >= 3` at threshold 0.8 |

Both count pairs are stored per event in the prediction databases, copied verbatim from
the probabilities file — the same arrays the nu-classifier's counts come from, so h8s3
means one thing across both pipelines. Verified 2026-09-07 by recomputing all three
quantities from `raw/labels`, `raw/channels` and `probs`.

The prefilter still scores **all** raw hits. These counts are analysis metadata, never a
selection.

## Part selection

Only parts the sig-noise probabilities file covers, because a part without counts cannot
carry either cut. That is 10,100 of the 20,004 muatm parts and all of nuatm and nue2 — the
uncovered parts have no arrays at all in that file, so their counts are NULL rather than
zero, and `>= 8` drops them. Training parts are excluded at scoring time, so everything in
the databases is out-of-training.

## Caveats

* **Weights.** `prime_prty[:, 5]`, applied within a class. Whether EventWeight is
  comparable *between* classes is `assumed`, not checked. Both versions are drawn.
* **`nue2`** is astrophysical nu_mu with an E^-2 spectrum, not electron neutrinos.
* **No live-time normalisation** exists for this MC, so figure 4 is a shape ratio and its
  level is not a rate.
* **Disjoint zenith hemispheres** in MC: muatm 94.2-179.9 deg, both neutrino classes
  0.11-90.00 deg with the cap at exactly 90.00. See `doc/claims_log.md`.
* **Two exp_full runs** are dropped by `reader.NOT_EXCLUDED` (four channels up to 3169.8
  p.e.); evidence in `inference/reader/spec.py`.

The predictions this rests on replaced an earlier three-column schema; the previous
databases are in `archive/prefilter_preds_before_hit_counts_260907/`, which is what
`report_260906_2310` was built from.
