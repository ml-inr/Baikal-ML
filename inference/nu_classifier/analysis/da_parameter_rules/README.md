# da_parameter_rules — сводные правила выбора λ и lr дискриминатора

Одна картинка `da_parameter_rules.png` (+ `results.csv`, `results_raw.csv`) по всем
прогонам **чистого протокола** (константные lr; λ-выключатель на 8-й эпохе; 1/10
данных; веса; z=128). Генератор — `analyze.py` (читает `da_config.yaml` и
`da_training_history.csv` каждого прогона; семейство отбирается по конфигу, не по
имени). Палитра — референсная из dataviz-скилла, взята как есть (node для
повторного запуска валидатора на машине нет; соблюдён задокументированный порог
ordinal-шкалы «не светлее ступени 250»). Смерть критика показана меткой ×/статусным
цветом, не одним лишь цветом.

## Правила (по состоянию на 2026-10-14)

1. **Контроль (λ=0)**: dom 0.760, game 0.766, разрыв −0.006.
2. **Изъятие насыщено**: любая живая λ>0 даёт game 0.70-0.76 (минимум ~0.706 при
   (0.01, 3e-2)); контроль 0.766. Ни λ (0.003→0.03), ни скорость критика изъятия
   не углубляют — только слепоту и обман.
3. **Обман растёт с λ**: разрыв ≈ −0.03..−0.14 (λ=0.003), −0.15..−0.26 (λ=0.01),
   −0.19..−0.26 (λ=0.03). Внутри λ растёт с D-LR до момента смерти критика.
4. **Смерть критика (AdamW)**: порог по D-LR падает с ростом λ: 1e-1 при λ=0.01,
   6e-2 при λ=0.03; при λ=0.003 до 6e-2 смертей нет (выше не измерено).
5. **SGD-критик (momentum 0) снимает смерть, но не обман** (уточнено по финалам
   14.10, эпохи 44-46): критик не схлопывается в ln2-фикспоинт (dom 0.53-0.60, не
   0.500), однако слепнет так же и обмана не меньше — при λ=0.01 разрывы −0.209/−0.210
   против −0.158 у AdamW-близнеца; при (3e-2, λ=0.003) SGD −0.141 ≈ AdamW −0.139.
   Ранняя (недозрелая) видимость «SGD честнее» опровергнута поздними эпохами.
6. **Мелкие λ (0.0003/0.001) пока = контроль** (разрыв ~0, dom 0.76) — на 10-12
   эпохах после включения эффекта нет; возможен поздний порог — в наблюдении.
7. **Класс неприкосновенен**: val AUC 0.9989-0.9996 везде, включая мёртвых
   критиков; SGD-энкодер (3e-2, m0.9, без warmup) держит 0.9994.

Практический выбор: λ ∈ [0.003, 0.01] (выше — только обман); D-LR не быстрее
3e-3..1e-2 (и никогда ≥ порога смерти); если нужен и быстрый, и живой критик —
SGD у критика.
