# feature_dimensionality — эффективная размерность пространства признаков

Порт двух октябрьских /tmp-диагностик (diag_dim.py, diag_pc_flip.py), на числа которых
опиралось решение об уменьшении модели; генерирующего скрипта в репозитории до этого
не было. Скрипт: `measure_dim.py` (фичи кэшируются в `<run>_feats.npz`, в git не
попадают). Конвенция: `amp_clip` конвертируется в нормированные единицы, как в тренере
(с ней эталонный чекпойнт воспроизводит записанные ранее числа: PR 1.4, угол
PC1-класс 0.6°, 0.517@1PC).

Замер 2026-10-12, чекпойнты `best_da_model.pth` (эталон — эпоха 21, весовой — 25,
маленькая — 72). По 8000 событий на класс (μ/ν/exp), свежий logreg, сплит 4000/4000,
только центрирование, сиды фиксированы; AUC-шум ~0.005–0.01.

| метрика (источник mc: μ+ν) | эталон d128 261002_0535 | весовой d128 _weights | маленькая d64 261010_1755 |
|---|---|---|---|
| размерность пространства | 128 | 128 | 64 |
| participation ratio | 1.4 | 1.3 | **1.2** |
| доля PC1 | 81.9% | 88.1% | **91.0%** |
| компонент на 90/95/99% | 2/2/15 | 2/2/2 | **1/2/13** |
| two-NN (источник / всё / exp) | 13.5 / 14.4 / 15.5 | 10.4 / 10.6 / 12.2 | 13.7 / 13.7 / 14.6 |
| класс (ν vs μ) @1 PC / все | 1.000 / 1.000 | 0.995 / 1.000 | 1.000 / 1.000 |
| домен чистый @1 PC / все | 0.769 / 0.856 | 0.759 / 0.807 | 0.739 / 0.809 |
| домен z-flip @1 PC / 64 / все | 0.519 / 0.666 / **0.707** | 0.510 / 0.644 / **0.653** | 0.520 / 0.592 / **0.592** |
| \|Δcls\| / \|Δdom z-flip\| | 12.18 / 0.42 | 10.44 / 0.41 | 6.36 / 0.16 |

Углы: знак PC1 из SVD произволен, поэтому берём по модулю 180°. Угол(PC1, класс):
0.6° / 2.4° / 0.5° (у маленькой SVD выдал PC1 с обратным знаком — 179.5° ≡ 0.5°).
Угол(класс, домен чистый) ≈ 173–178° у всех трёх: классовая и доменная разности
почти антипараллельны везде. Углы с домен-флип-разностью не интерпретируем — вектор
микроскопический (норма 0.16–0.42 против ~10 у класса), направление шумное.

Чтения:
1. Обе новые модели **сильнее сжаты линейно**, чем эталон, и по-разному: весовая —
   всё в 2 компонентах (PC1 88%); маленькая — почти всё в одной (PC1 91%, 90%
   дисперсии в 1 компоненте), но с более толстым диффузным хвостом (two-NN 13.7 —
   как у эталона, тогда как у весовой 10.4).
2. Класс у всех трёх целиком в первой оси (у весовой 0.995@1PC — чуть расплылся).
3. Доменная различимость: чистая у всех ~0.81–0.86; переживающая z-flip —
   монотонно слабеет по ряду эталон 0.707 → весовая 0.653 → маленькая 0.592.
   Хвостовой «резервуар» домена у маленькой читается только с самых последних
   измерений (0.526@16 → 0.592@64), то есть резервуар тоньше.

Запуск: `python inference/nu_classifier/analysis/feature_dimensionality/measure_dim.py --run <каталог прогона>`
