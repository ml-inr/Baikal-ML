# Nu-Classifier Prediction Results

Output HDF5 files produced by `predict_mc.py` and `predict_exp.py`.

---

## MC predictions — `mc_preds_{model_tag}.h5`

Generated by `inference/nu_classifier_model/predict_mc.py`
from `baikal_mc_merged.h5` + precomputed sig-noise probs h5.

```
/baikal_mc_merged/
  {ptype}/                        # muatm_2020 | nuatm_2020 | nue2_2020
    scores/{pk}/data              (n_sel,)  float32  — nu-classifier sigmoid score
    n_sig_hits/{pk}/data          (n_sel,)  int32    — sig-noise filtered hit count per event
    n_sig_strings/{pk}/data       (n_sel,)  int32    — unique string count among sig hits
    event_ids/{pk}/data           (n_sel,)  int32    — 0-based event index within part pk
                                                       in the source baikal_mc_merged.h5
```

`{pk}` = HDF5 part key, e.g. `part_0`, `part_1`, …
`n_sel` = number of events passing the event cuts (`--min-hits`, `--min-strings`).

To recover raw hits for event `i`:
```python
eid = mc_preds["baikal_mc_merged/{ptype}/event_ids/{pk}/data"][i]
ev_starts = mc_h5["{ptype}/raw/ev_starts/{pk}/data"][:]
s, e = ev_starts[eid], ev_starts[eid + 1]
hits = mc_h5["{ptype}/raw/data/{pk}/data"][s:e]   # (n_hits, 5) float32
```

## Exp predictions — `exp_preds_{model_tag}.h5`

Generated by `inference/nu_classifier_model/predict_exp.py`
from `exp_reco.h5` with on-the-fly sig-noise filtering.

```
/exp_reco/
  scores/{pk}/data                (n_sel,)  float32  — nu-classifier sigmoid score
  n_sig_hits/{pk}/data            (n_sel,)  int32    — sig-noise filtered hit count per event
  n_sig_strings/{pk}/data         (n_sel,)  int32    — unique string count among sig hits
  event_ids/{pk}/data             (n_sel,)  int32    — 0-based event index within part pk
                                                       in the source exp_reco.h5
```

`{pk}` = part key, e.g. `part_s2020_c01_r0001`, …

To recover raw hits for event `i`:
```python
eid = exp_preds["exp_reco/event_ids/{pk}/data"][i]
ev_starts = exp_h5["exp_reco/raw/ev_starts/{pk}/data"][:]
s, e = ev_starts[eid], ev_starts[eid + 1]
hits = exp_h5["exp_reco/raw/data/{pk}/data"][s:e]   # (n_hits, 5) float32
```

---

## Model tag

The `{model_tag}` in the filename is the name of the checkpoint's parent directory,
e.g. `260508_1724_da_nu_classifier_h5s0_lambda0.01_thr0.8_seed32`.

## Sig-noise threshold

Hit filtering and event cuts are applied at the threshold configured in
`run_predict_mc.sh` / `run_predict_exp.sh` (`THRESHOLD`, `MIN_HITS`, `MIN_STRINGS`).
The threshold value is **not stored** in the h5 — check the shell script or logs.
